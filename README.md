## Selected Work

### AutoConcept — Training-Free Concept-Guided Reranking

First-author work accepted at **PRICAI 2026 (CCF-C)**. AutoConcept extracts reusable concepts from same-category item text and uses them to rerank metadata-available composed image retrieval results—without additional model training.

[[arXiv]](https://arxiv.org/abs/2609.01456) · [[Paper]](https://realclearwave.github.io/assets/papers/autoconcept-pricai-2026.pdf)

### UI-RA — UI Reasoning Alignment

Developed a multimodal post-training pipeline around **Qwen3-VL** with grounding-aware SFT, GRPO, on-policy distillation, reverse-KL output distillation, and attention distillation. In controlled experiments, the 4B student improved from **50.1% to 83.5% on UIDR-Bench**, exceeding the untuned 32B teacher at 80.2%; attention distillation contributed a further **+2.7 percentage points**.

### AMEND — Agentic Multi-Critic Editing for Non-Toxic Discourse

Designed a constrained multi-agent editing pipeline that combines specialized critics, minimal repair, semantic paraphrasing, trace reuse, and residual-span gating for controllable text detoxification.

[[ACL-style Technical Report]](https://realclearwave.github.io/assets/papers/amend-acl-report.pdf)
